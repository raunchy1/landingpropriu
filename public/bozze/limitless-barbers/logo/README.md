# Limitless Barbers — sistema logo

Marchio ridisegnato per la bozza WebSardegna. Tutti i file sono SVG con i
testi già convertiti in tracciati: non dipendono da font installati.

## File

| File | Uso |
|---|---|
| `limitless-wordmark-gold.svg` | Logotipo orizzontale, oro. Header del sito. |
| `limitless-wordmark-ivory.svg` | Versione avorio, per fondi in cui l'oro non stacca. |
| `limitless-wordmark-black.svg` | Versione nera, per stampe su fondo chiaro. |
| `limitless-monogram-gold.svg` | Monogramma LB nel tondo, oro. Social, timbri, packaging. |
| `limitless-monogram-ivory.svg` | Monogramma avorio. |
| `limitless-lockup-stacked-gold.svg` | Lockup verticale con slogan. Footer, insegne, stampe. |
| `limitless-lockup-stacked-ivory.svg` | Lockup verticale avorio. |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Icone browser e iOS. |

## Costruzione

- Carattere: **Bodoni Moda** (didone ad alto contrasto, optical size 96),
  spaziatura +0,175 em sul logotipo, +0,62 em su `BARBERS`.
- Filetti verticali con i micro-testi `EST` / `MMXXVI`, ripresi dal lettering
  che il salone usa già su t-shirt e prodotti.
- Monogramma: `L` e `B` separate da un filetto, dentro un doppio cerchio
  (1,3 pt + 0,5 pt), con `MMXXVI` in basso.

## Colori

| Nome | HEX |
|---|---|
| Oro | `#C9A96E` |
| Oro chiaro (luce del gradiente) | `#F2E4C3` |
| Oro scuro (ombra del gradiente) | `#8C6B36` |
| Avorio | `#F2EDE4` |
| Nero | `#0B0B0C` |

Le versioni oro usano un gradiente metallico in `userSpaceOnUse`: va bene per
schermo e stampa digitale; per la serigrafia usare l'oro pieno `#C9A96E`.

## Regole minime

- Area di rispetto: almeno l'altezza della `L` su ogni lato.
- Dimensione minima del logotipo orizzontale: 160 px di larghezza (sotto,
  usare il monogramma).
- Non ruotare, non deformare, non cambiare la spaziatura tra le lettere.
- Fondo sempre scuro per le versioni oro e avorio.
